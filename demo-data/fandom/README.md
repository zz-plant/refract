# Fandom Demo Data

Hand-written events about pages on public Fandom wikis. They show canon disputes, retcons, and version-driven changes in fictional universes.

## Contents

- `star-wars/` — Darth Vader (`index.jsonl`), Luke Skywalker (`luke-skywalker.jsonl`): parentage reveals, Dark Side chronology
- `marvel/` — Character pages with multiple retcons (`index.jsonl`)
- `minecraft/` — Game mechanics pages with version-driven changes (`index.jsonl`)
- `index.jsonl` — Six summary events across the three subdirectories
